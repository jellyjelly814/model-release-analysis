         智谱 GLM-5.3 模型 API 上线，权重下周五开源 

         
             

                     2026/8/19 9:10:56 
                     来源： IT之家 
                     作者： 远洋 

                     责编： 远洋 
             

             

                 
                     评论： 
             
         



         
            
             IT之家  8 月 19 日消息，智谱今日宣布，GLM-5.3 API 即日起正式上线。模型擅长复杂编码、防御性网络安全以及长程任务。 官方称，GLM-5.3 在全球权威的 Artificial Analysis Intelligence Index（AA 综合智能指数）中取得 60 分，进入全球前沿模型能力区间，与 Claude Fable 5、GPT-5.6 Sol 等闭源旗舰模型处于同一水平，并与 Kimi K3 并列开源模型第一。 AA 指数覆盖知识、推理、编码、智能体等多项评测，衡量模型在真实复杂任务中的综合能力 在达到同档智能水平的同时，GLM-5.3 以更小的参数规模与更低的调用成本，显著降低了前沿模型能力的使用门槛。 图中，纵轴为 Artificial Analysis 智能指数，横轴为完成单个任务的平均成本。GLM-5.3 以前沿旗舰模型中最低的单任务成本， 处于高智能、低成本的最具吸引力区间 ，同时将前沿模型“智能 — 成本”的帕累托前沿大幅推进。 官方称， GLM-5.3 追求的不只是智能上限，也致力于提升单位成本所能获得的智能。 随着 API 正式开放，前沿智能将进入更多开发者、企业和知识工作者的真实工作场景。 据IT之家了解，GLM-5.3 与上一代 GLM-5.2 沿用同一基础模型，性能提升主要来自后训练。 目前，GLM-5.3 已接入 ZCode 等编码平台，并纳入 GLM Coding Plan。API 已开放调用，定价与 GLM-5.2 保持不变。模型权重将于下周五开源。
