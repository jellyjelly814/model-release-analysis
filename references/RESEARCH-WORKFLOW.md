# 模型发布研究与证据工作流

本文件只说明研究与取证。默认最终交付按 `SKILL.md` 同步飞书；用户明确只读时不写入。每条关键判断还要进入 `CLAIMS-AND-EVALS.md` 的事实清单。

## 1. 来源优先级

按以下顺序查找并保存原始 URL、抓取日期和模型版本：

1. 官方发布页、开发者文档、API 文档、模型卡、技术报告、System Card。
2. 官方社媒、官方演示、官方 GitHub 或模型仓库。
3. 独立 benchmark、Arena、模型市场或可复现第三方测试。
4. 合作伙伴、客户、媒体、KOL 和社区复现。

搜索摘要只能用于发现链接，不能作为事实来源。若网页只是 React 空壳、404、登录墙或验证页，把它记录为失败证据，不从页面标题推断正文。

## 2. 研究字段

至少核对：

- 模型名、公司、精确版本、发布日期与时区。
- 输入/输出模态、上下文、最大输出、参数或架构变化（仅在公开时写）。
- API 与产品入口、区域或白名单限制。
- 输入、输出、缓存、批处理等价格口径。
- Coding、Agent、computer use、知识工作、推理、视觉、安全等可比指标。
- 官方 Case 的任务、工具、过程、结果、人工介入和限制。
- 官方首发、合作伙伴、客户评价、社区支持与质疑。

每条 benchmark 都保留模型版本、测试集版本、harness、工具权限、采样设置和发布日期。无法确认这些条件时，不做精确横向排序。

## 3. 事实边界

正文把内容分成五类：

| 类型 | 写法 |
|---|---|
| 已核对事实 | 直接陈述并给原始来源 |
| 官方自测 | 明确写“官方结果/厂商披露” |
| 独立实测 | 写明平台、版本和评测口径 |
| 外部观点 | 标明作者或组织，不升级为事实 |
| 推断 | 标“观察/可能”，说明推断依据 |

同代参考模型的数据不能冒充当前模型独立实测。模块、内核或单项指标不能改写为端到端系统提升。

## 4. 中国站点

微信公众号优先使用用户给出的 `mp.weixin.qq.com` 原文。可用只读请求保存 HTML，提取 `data-src` 图片 URL 时先解码 `&amp;`；下载 `mmbiz.qpic.cn` 图片使用空 Referer。页面出现“环境异常”或“完成验证”时停止解析并记录失败。

知乎、微博、B 站等站点优先使用当前运行时已登录浏览器或公开页面。不要绕过登录、验证码或访问控制，不自动安装浏览器组件。

## 5. 图片筛选

允许的证据图：

- 完整 benchmark、性能曲线、架构图、定价表。
- 真实 Case 的输入、过程或结果。
- 完整官方/合作伙伴/社区帖子。
- GitHub、模型仓库或生态入口中能直接看到模型名和接入状态的页面。

拒绝：纯海报、logo、无关页面、骨架屏、弹窗遮挡、半截表格、裁掉坐标轴/图例/脚注、不可读小字。裁图无法保留完整语义时保留完整页面。

每张候选图都要：

1. 用视觉工具打开检查。
2. 用文件签名确认是 PNG/JPEG/GIF/WebP，不依赖扩展名。
3. 计算 SHA-256 并写入 manifest。
4. 记录 `source_class`、原始 URL、页面区块、截图方法和可见结论。
5. 写入后记录父页/子页实际 block ID，并回读核对。

同一文件内容、同一远端 block 或同一原图的重复裁切不能当作两份独立证据。

## 6. 开场四列证据墙

选择四张能快速建立全貌的图，至少覆盖三种来源类别：

- `official_page`
- `official_social`
- `github_or_model_repo`
- `independent_benchmark`
- `external_media_or_kol`

同一官方 benchmark 的完整图、局部图和放大图仍是一种内容。四张都必须在子文档 manifest 中有 `child_image_block`，并在后文找到文字解释。

## 7. Artificial Analysis

先检查真实模型页和模型目录，再选择状态：

- `available`：模型页有可用内容。至少取两张不同区块，一张模型总览，一张 benchmark/排名/成本分解；两张必须有不同哈希和 child block。
- `checked_unavailable`：已检查但模型未收录、页面 404 或没有该版本。记录检查 URL、原因，并用其他独立来源替代。
- `not_applicable`：该发布类型不适用于该平台。仍记录检查 URL、原因和替代证据。

不要用普通官网图冒充 Artificial Analysis，也不要要求缺失平台凭空产生截图。

## 8. 社媒证据

社媒图是条件证据。找得到且可读时，完整保留作者、正文、媒体、时间与互动区，A/C 均在范围内时同时用于父页和子页，单范围时只绑定相应页面；找不到时保留 URL/失败原因和其他发布证据，不用登录墙截图占位。

## 9. 下载与留存

所有 HTML、PDF、图片和日志只写入已确认研究目录。文件小于 100 字节、签名错误或内容无效时标记 rejected 并保留，不自动删除。公开网页只允许 GET/HEAD；不向外部站点上传本地内容。
